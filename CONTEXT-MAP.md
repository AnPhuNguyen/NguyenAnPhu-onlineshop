# Context Map

This project is a multi-context monorepo containing a Shop frontend, an Admin frontend, and a NestJS backend.

## Contexts

- **Shop**: [litecommerce-shop/CONTEXT.md](./litecommerce-shop/CONTEXT.md)
  - React-based customer-facing shop.
- **Admin**: [litecommerce-admin/CONTEXT.md](./litecommerce-admin/CONTEXT.md)
  - React-based administration portal.
- **Backend**: [litecommerce-backend/CONTEXT.md](./litecommerce-backend/CONTEXT.md)
  - NestJS-based API serving both Shop and Admin.
